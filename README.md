# poshan-statistics
This project presents an interactive Power BI dashboard built using a sample POSHAN Statistics dataset. It explores Anganwadi Centre (AWC) infrastructure and performance, child nutrition indicators, and food and supplement coverage.

Dataset source:https://drive.google.com/file/d/1-Mrrwpp6ZZ5W6taFSrTr-8JSIybY2Cj5/view?usp=drive_link
The dashboard helps users compare reported indicators across states and
districts and explore changes across reporting dates.

## Dashboard Pages

### 1. Executive Overview

Provides a high-level summary of indicators such as total AWCs and
eligible beneficiaries. State-wise comparisons, a map, and Date, State,
and District slicers support exploration.

### 2. AWC Performance Analysis

Focuses on Anganwadi Centre infrastructure and operations: - Total,
rural, urban, and tribal AWCs - AWCs with drinking water - AWCs with
toilets - AWCs in their own buildings - AWC opening-day indicators -
State-wise comparisons and map view

### 3. Child & Nutrition Analysis

Explores reported child and nutrition indicators: - Growth-monitored
children - Stunted children - Underweight children - Children with acute
malnutrition - State comparisons and time trends

### 4. Food & Supplement Coverage

Examines reported food and supplement indicators: - Hot Cooked Meal
(HCM) measures - Take Home Ration (THR) measures - Children attending

AWCs for 21 days and 25 days - State-wise comparisons and a detailed
table
